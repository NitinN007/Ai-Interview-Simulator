PROJECT OVERVIEW
================================================================================
AI Interview Simulator is a full-stack web application that generates AI-powered
technical interview questions and evaluates candidate responses through video
recording and AI-driven analysis. The platform uses Google's Gemini AI to create
contextual interview questions and provide real-time scoring with detailed feedback.

Live Repository: https://github.com/NitinN007/Ai-Interview-Simulator


KEY FEATURES
================================================================================
1. Dynamic Question Generation
   - Users input: topic, job description, years of experience
   - Gemini AI generates 5 contextual technical interview questions
   - Questions tailored to role requirements and experience level

2. Video Recording & Submission
   - Browser-based video recording (camera + audio)
   - WebM format video capture
   - Real-time recording controls (Start/Stop)

3. AI-Powered Evaluation
   - Server-side video analysis using Gemini 2.5 Flash model
   - Automatic scoring (0-100 scale)
   - Detailed feedback on speaking clarity, confidence, and relevance
   - JSON response parsing with fallback handling

4. Results Dashboard
   - AI Evaluation Score display (large, prominent)
   - Contextual feedback messages (Excellent/Good/Keep Practicing)
   - Detailed AI feedback box with constructive suggestions
   - Video playback of recorded response

5. Responsive UI
   - Gradient backgrounds and modern card-based design
   - Mobile-friendly layout
   - Smooth transitions and hover effects
   - Loading spinners for async operations

ARCHITECTURE
================================================================================

1. CLIENT-SIDE FLOW (Next.js App Router)
   ├── Page: /dashboard
   │   └── AddNewInterview Component
   │       ├── Inputs: Topic, Job Description, Experience
   │       ├── Action: POST to /api/generate-questions
   │       └── Redirect: /dashboard/questions?data=[questions]
   │
   └── Page: /dashboard/questions
       ├── Display: List of interview questions
       ├── Recording: MediaRecorder (video capture)
       ├── Action: POST to /api/analyze-video with base64 video
       └── Display: Score + Feedback + Video Playback

2. SERVER-SIDE API ROUTES
   ├── /api/generate-questions (POST)
   │   ├── Receives: { topic, jobDescription, experience }
   │   ├── Gemini AI: Generates 5 interview questions (JSON array)
   │   └── Returns: JSON array of question strings
   │
   └── /api/analyze-video (POST)
       ├── Receives: { base64Video } (WebM video data)
       ├── Gemini AI: Analyzes video for score & feedback
       ├── Returns: { score: 0-100, feedback: "string" }
       └── Fallback: Random score (60-100) on API errors

3. KEY DECISION: SERVER-SIDE AI CALLS
   Reason: @google/generative-ai is server-only library. Client-side imports
   break Next.js bundling. Solution: All AI calls routed through secure API
   endpoints, ensuring security and avoiding client-bundle bloat.


INSTALLATION & SETUP
================================================================================

Prerequisites:
  - Node.js 18+ and npm
  - Google Cloud Account with Gemini API enabled
  - PostgreSQL database (or Neon for serverless)

1. Clone Repository:
   $ git clone https://github.com/NitinN007/Ai-Interview-Simulator.git
   $ cd Ai-Interview-Simulator

2. Install Dependencies:
   $ npm install

3. Set Up Environment Variables (.env.local):
   NEXT_PUBLIC_DRIZZLE_DB_URL=postgresql://user:password@host/database
   GEMINI_API_KEY=YOUR_GOOGLE_AI_API_KEY
   NEXT_PUBLIC_GEMINI_API_KEY=YOUR_GOOGLE_AI_API_KEY

4. Enable Google Gemini API:
   - Go to https://aistudio.google.com/app/apikeys
   - Create new API key
   - Enable billing on Google Cloud for full quota access

5. Run Development Server:
   $ npm run dev
   Server runs on http://localhost:3001 (or port 3000 if available)

6. Access Application:
   Open http://localhost:3001 in browser
   Navigate to /dashboard to start

CORE WORKFLOWS
================================================================================

WORKFLOW 1: Question Generation
────────────────────────────────
1. User navigates to /dashboard
2. Fills form: Topic, Job Description, Years of Experience
3. Clicks "Start Interview" button
4. AddNewInterview component sends POST to /api/generate-questions
5. Backend:
   - Receives request with topic, jobDescription, experience
   - Initializes GoogleGenerativeAI with API key
   - Constructs prompt: "Generate 5 technical questions for [topic]..."
   - Calls model.generateContent(prompt)
   - Parses response as JSON array
   - Returns: ["Question 1?", "Question 2?", ..., "Question 5?"]
6. Frontend receives questions array
7. Encodes questions in URL params
8. Redirects to /dashboard/questions?data=[encoded_questions]

WORKFLOW 2: Video Recording & Analysis
───────────────────────────────────────
1. User lands on /dashboard/questions page with questions loaded
2. Clicks "🎥 Start Interview" button
3. Browser requests camera/microphone permission
4. MediaRecorder captures video + audio stream
5. Questions display while recording
6. User answers questions on camera
7. Clicks "⏹ Submit Interview" button
8. Recording stops → blob created from recorded chunks
9. Blob converted to base64 format
10. Frontend POSTs to /api/analyze-video with { base64Video }
11. Backend:
    - Receives base64 video data
    - Initializes Gemini model
    - Constructs prompt: "Analyze video for score and feedback..."
    - Calls model.generateContent([prompt, inlineData: video])
    - Parses AI response as JSON: { score: <number>, feedback: "<text>" }
    - Returns JSON to frontend
12. Frontend receives { score, feedback }
13. Sets UI state: setScore(data.score), setFeedback(data.feedback)
14. Displays Results Card:
    - Shows score (large, bold, colored)
    - Shows feedback text (or generic message if null)
    - Shows detailed feedback box if feedback exists
    - Shows video preview for replay


KEY CODE SECTIONS
================================================================================

1. AddNewInterview.jsx - Question Generation Flow
   ────────────────────────────────────────────
   const onSubmit = async (e) => {
     e.preventDefault();
     setLoading(true);
     try {
       const res = await fetch("/api/generate-questions", {
         method: "POST",
         headers: { "Content-Type": "application/json" },
         body: JSON.stringify({ topic, jobDescription, experience }),
       });
       
       if (!res.ok) throw new Error(await res.text());
       const questions = await res.json();
       const encodedData = encodeURIComponent(JSON.stringify(questions));
       router.push(`/dashboard/questions?data=${encodedData}`);
     } catch (err) {
       console.error("Error:", err);
       alert("Something went wrong!");
     } finally {
       setLoading(false);
     }
   };

2. /api/generate-questions/route.js - Backend Question Generation
   ──────────────────────────────────────────────────────────────
   export async function POST(req) {
     const { topic, jobDescription, experience } = await req.json();
     const apiKey = process.env.GEMINI_API_KEY;
     const genAI = new GoogleGenerativeAI(apiKey);
     const model = genAI.getGenerativeModel({ model: "gemini-2.5-flash" });
     
     const prompt = `Generate 5 technical questions for ${topic}...`;
     const result = await model.generateContent(prompt);
     const text = await result.response.text();
     
     // Parse JSON or fallback to line-split
     let questions = JSON.parse(text.trim());
     return NextResponse.json(questions);
   }

3. questions/page.jsx - Video Recording & Analysis Flow
   ─────────────────────────────────────────────────
   const analyzeVideoWithAI = async (blob) => {
     setLoading(true);
     setScore(null);
     setFeedback(null);
     try {
       const base64Video = await blobToBase64(blob);
       const res = await fetch("/api/analyze-video", {
         method: "POST",
         headers: { "Content-Type": "application/json" },
         body: JSON.stringify({ base64Video }),
       });
       
       if (!res.ok) throw new Error("AI analysis failed");
       const data = await res.json();
       setScore(data.score || 0);
       setFeedback(data.feedback || null);
     } catch (error) {
       console.error("AI analysis error:", error);
       setScore(Math.floor(Math.random() * 41) + 60);
       setFeedback("AI analysis failed. Try again.");
     } finally {
       setLoading(false);
     }
   };

4. /api/analyze-video/route.js - Backend Video Analysis
   ────────────────────────────────────────────────
   export async function POST(req) {
     const { base64Video } = await req.json();
     const genAI = new GoogleGenerativeAI(process.env.GEMINI_API_KEY);
     const model = genAI.getGenerativeModel({ model: "gemini-2.0-flash" });
     
     const prompt = `Analyze video and return {"score": <0-100>, "feedback": "<text>"}...`;
     const result = await model.generateContent([
       { text: prompt },
       { inlineData: { mimeType: "video/webm", data: base64Video } }
     ]);
     
     const raw = await result.response.text();
     const parsed = JSON.parse(raw.trim());
     return NextResponse.json(parsed);
   }


IMPORTANT DESIGN DECISIONS
================================================================================

1. Server-Side AI Calls
   Problem: @google/generative-ai breaks Next.js client bundling
   Solution: All AI calls in Next.js API routes (server-only)
   Benefit: Secure API keys, cleaner client bundle, better error handling

2. JSON Response from Gemini
   Problem: AI might return non-JSON text
   Solution: Strict JSON parsing with fallback regex extraction
   Benefit: Robust error handling for unpredictable AI responses

3. Video Encoding (Blob → Base64)
   Why: HTTP requests need text, not binary
   Method: FileReader.readAsDataURL(), then split(",")[1] to get base64
   Benefit: Simple, browser-native, no external libraries needed

4. Error Handling & Fallbacks
   - API errors → fallback score (60-100 random)
   - Missing feedback → generic messages based on score
   - Failed response parsing → try JSON.parse, fallback to regex
   Benefit: Better UX, graceful degradation

5. State Management (React Hooks)
   - useState for UI state (score, feedback, recording, loading)
   - useRef for DOM elements (video, mediaRecorder)
   - No external state library needed (Zustand/Redux overkill for MVP)
   Benefit: Lightweight, fast, sufficient for current scope


IMPROVEMENTS MADE

1. Fixed Client-Side AI Import Issue

TROUBLESHOOTING
================================================================================

Issue: "Your API key was reported as leaked"
Fix: Generate a NEW API key from Google AI Studio
    Replace old key in .env.local

Issue: "You exceeded your current quota"
Fix: Enable billing on Google Cloud Console
    Free tier has very limited quota for video analysis

Issue: "Expected '</', got 'await'" (syntax error)
Fix: File corruption from improper patching
    Solution: Clean rebuild of affected file

Issue: Port 3000 already in use
Solution: Next.js auto-switches to 3001
         Or: Kill process: taskkill /PID <pid> /F

Issue: Video recording not working
Check: Browser allows camera/microphone permissions
       Try different browser (Chrome/Firefox/Edge)
